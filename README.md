# 🧪 화학 반응 단계별 시뮬레이터

## 1. 프로젝트 소개

**화학 반응 단계별 시뮬레이터**는 화학 반응식의 계수에 따라 반응물과 생성물의 분자 수가 어떻게 달라지는지 확인하는 **Streamlit 웹 프로그램**입니다.

사용자가 화학 반응을 선택하고 반응물의 초기 분자 수를 입력한 뒤 **실행** 버튼을 누르면, 프로그램은 반응이 가능한 동안 반응을 한 번씩 반복합니다. 각 단계의 분자 수를 표로 기록하여 **반응식의 계수, 반응물의 소모, 생성물의 형성, 반응이 멈추는 조건**을 살펴볼 수 있도록 만들었습니다.

Python의 변수, 조건문, 반복문, 함수, 리스트를 중심으로 구현했으며, 반응 정보를 `reactions.txt`로 분리하여 새로운 반응을 쉽게 추가할 수 있게 구성했습니다.

> **개발 상태 안내:** 단계별 계산과 기록 기능은 코드에 구현되어 있습니다. 다만 현재 `main.py`의 `show_result()`에 변수명 오류(`졸려`)가 있어 **반응이 한 번 이상 진행되면 최종 결과 설명을 출력하는 과정에서 오류가 발생**합니다. 아래 ‘확인된 오류 및 제한 사항’을 참고해 주세요.

## 2. 주요 기능

| 기능 | 설명 |
| --- | --- |
| **화학 반응 선택** | 사이드바에서 `reactions.txt`에 등록된 반응을 선택합니다. |
| **반응 정보 표시** | 선택한 반응의 반응식, 반응 종류, 설명을 보여줍니다. |
| **반응식 자동 해석** | 반응물을 생성물과 구분하고, 각 화학식과 반응 계수를 추출합니다. 계수 생략 시 `1`로 인식합니다. |
| **반응물 개수 입력** | 선택한 반응의 반응물 종류에 따라 분자 수 입력칸이 자동으로 생성됩니다. 초기 입력값은 `0`입니다. |
| **반응 가능 여부 판단** | 모든 반응물의 분자 수가 해당 반응 계수 이상인지 확인합니다. |
| **단계별 분자 수 계산** | 한 단계마다 반응물은 계수만큼 감소하고 생성물은 계수만큼 증가합니다. 반응할 수 없을 때까지 자동 반복합니다. |
| **단계별 기록 표** | 0단계(초기 상태)부터 마지막 단계까지 각 물질의 분자 수를 표로 보여줍니다. |
| **최종 결과 설명** | 모두 소모된 반응물, 다음 반응에 부족한 반응물, 남은 반응물, 생성물을 설명하도록 작성되어 있습니다. **현재 변수명 오류 수정이 필요합니다.** |
| **입력 변경 시 기록 초기화** | 반응을 바꾸거나 분자 수 입력값을 변경하면 이전 실험 기록을 초기화합니다. |

## 3. 등록된 화학 반응

| 반응 이름 | 반응식 | 반응 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 반응 |
| 메테인 연소 | `CH4 + 2O2 -> CO2 + 2H2O` | 연소 반응 |

새 반응은 `reactions.txt`에 추가할 수 있습니다.

## 4. 프로그램 사용 방법

1. 왼쪽 **사이드바의 ‘반응 선택’** 메뉴에서 실험할 화학 반응을 선택합니다.
2. 메인 화면에서 **반응식, 종류, 설명**을 확인합니다.
3. 각 반응물의 **초기 분자 수**를 입력합니다.
4. 반응물과 생성물의 **화학식 및 계수 표**를 확인합니다.
5. 사이드바의 **‘실행’** 버튼을 누릅니다.
6. **‘단계별 분자 수’** 표에서 반응이 진행될 때마다 분자 수가 어떻게 바뀌었는지 확인합니다.
7. 최종 결과 설명에서는 남은 반응물과 생성물을 확인할 수 있도록 설계했습니다. **단, 현재 코드의 변수명 오류를 먼저 수정해야 합니다.**

**참고:** 실행 버튼을 한 번 누르면 반응이 가능한 모든 단계가 자동으로 계산됩니다. 단계마다 버튼을 따로 누르는 방식은 아닙니다.

## 5. 단계별 계산 예시

**물 생성 반응:** `2H2 + O2 -> 2H2O`

수소 분자 **5개**, 산소 분자 **2개**를 입력했다면, 한 번의 반응마다 수소 분자 2개와 산소 분자 1개가 소모되고 물 분자 2개가 생성됩니다.

| 단계 | H2 | O2 | H2O |
| --- | ---: | ---: | ---: |
| 0 (초기) | 5 | 2 | 0 |
| 1 | 3 | 1 | 2 |
| 2 | 1 | 0 | 4 |

2단계 후에는 수소가 1개 남고 산소가 0개이므로, 다음 반응에 필요한 분자 수가 부족해 반응이 종료됩니다. **최종적으로 수소 1개가 남고 물 4개가 생성됩니다.**

이 표는 **현재 계산 로직을 설명하기 위한 예시**입니다. 실제 앱에서는 최종 설명 출력 부분의 변수명 오류가 해결되어야 전체 결과가 정상 표시됩니다.

## 6. 프로젝트 파일 구조

```text
chemistry-reaction-simulator/
├── main.py           # 프로그램의 화면, 반응식 해석, 단계별 계산
├── reactions.txt     # 화학 반응 데이터
├── requirements.txt  # 실행에 필요한 라이브러리
└── README.md         # 프로젝트 소개 및 사용 설명
```

### main.py의 함수별 역할

| 함수 | 역할 |
| --- | --- |
| `read_reactions()` | `reactions.txt`를 읽고 반응 정보들을 리스트에 저장합니다. |
| `parse_reaction()` | 반응식을 `->`, `+`를 기준으로 나누고 화학식과 계수를 추출합니다. |
| `react_once()` | 반응이 가능한지 확인한 뒤, 반응물과 생성물의 분자 수를 한 단계 변화시킵니다. |
| `show_table()` | 반응물 또는 생성물의 화학식과 계수를 표로 나타냅니다. |
| `show_history_table()` | 각 단계의 분자 수 변화를 표로 나타냅니다. |
| `show_result()` | 최종 소모·부족·잔여 반응물과 생성물을 설명합니다. 현재 변수명 오류가 있습니다. |
| `show_screen()` | 사이드바, 입력창, 실행 버튼, 결과 영역을 구성하고 함수를 연결합니다. |

## 7. 새로운 화학 반응 추가하기

`reactions.txt`에 다음 형식으로 **한 줄씩** 반응 정보를 작성합니다.

```text
이름,반응식,종류,설명
```

예를 들어, 다음 한 줄을 추가할 수 있습니다.

```text
암모니아 생성,N2 + 3H2 -> 2NH3,합성 반응,질소와 수소가 반응하여 암모니아가 생성된다
```

파일을 GitHub에 저장하면 배포 앱의 코드가 업데이트된 후 선택 메뉴에서도 새 반응을 사용할 수 있습니다.

**반응 정보 작성 규칙**

- 항목 순서는 **이름, 반응식, 종류, 설명**입니다.
- 반응물과 생성물은 `->`로 구분합니다.
- 여러 물질은 `+`로 구분합니다.
- 반응 계수는 화학식 앞에 적으며, 계수 `1`은 생략할 수 있습니다.
- 반응식은 **미리 계수가 맞춰진 상태**로 입력해야 합니다. 이 프로그램은 계수를 자동으로 맞추거나 화학식 내부의 원자 수를 검증하지 않습니다.

## 8. 사용 기술 및 실행 환경

- **Python:** 조건문, 반복문, 함수, 리스트를 사용한 계산 및 데이터 처리
- **Streamlit:** 사이드바, 입력창, 버튼, 표 등 웹 화면 구성
- **GitHub:** 소스 코드와 반응 데이터 관리
- **Streamlit Community Cloud:** 웹 앱 배포

`requirements.txt`:

```text
streamlit
```

### 배포 방법

1. GitHub 저장소에 `main.py`, `reactions.txt`, `requirements.txt`, `README.md`를 저장합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속합니다.
3. 배포할 GitHub 저장소와 브랜치를 선택합니다.
4. 앱 실행 파일을 `main.py`로 지정하고 배포합니다.

## 9. 확인된 오류 및 제한 사항

- **최종 결과 출력 오류:** 현재 `main.py`의 `show_result()`에는 정의되지 않은 변수 `졸려`가 세 번 사용되었습니다. 세 곳 모두 기존에 생성한 리스트 변수 `exhausted`로 바꿔야 반응이 진행된 경우 최종 결과 설명이 정상 출력됩니다.
- **입력 데이터 형식:** `reactions.txt`의 각 줄은 정해진 네 가지 항목과 반응식 형식을 따라야 합니다. 잘못된 입력을 모두 검증하는 기능은 아직 없습니다.
- **화학적 가정:** 반응은 반응식에 적힌 정수 계수에 따라 완전히 진행되는 것으로 가정합니다. 실제 반응 속도, 온도, 압력, 평형, 반응 효율은 계산하지 않습니다.

## 11. 프로젝트 목표

화학 반응식을 단순히 외우는 데 그치지 않고, **반응 계수가 실제 분자 수 변화와 어떤 관계가 있는지** 직접 입력하고 계산 결과를 관찰하며 이해하는 것이 이 프로젝트의 목표입니다. 반응 데이터와 프로그램 코드를 분리하고 기능별 함수를 활용해, 새로운 반응을 추가하거나 기능을 확장하기 쉬운 구조를 구현하고자 했습니다.
