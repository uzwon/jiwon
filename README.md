# 🧪 화학 반응 단계별 시뮬레이터

## 1. 프로젝트 소개

**화학 반응 단계별 시뮬레이터**는 화학 반응식의 계수에 따라 반응물과 생성물의 **분자 수가 단계별로 어떻게 변하는지** 계산하고, 그 결과를 표와 그래프로 확인할 수 있는 **Python·Streamlit 웹 프로그램**입니다.

사용자가 화학 반응을 선택하고 반응물의 초기 분자 수를 입력한 다음 **실행** 버튼을 누르면, 반응물이 충분한 동안 반응을 한 번씩 반복 계산합니다. 각 단계에서 소모되는 반응물과 생성되는 물질의 개수를 기록하고, 반응이 멈춘 이유와 최종적으로 남은 물질을 확인할 수 있습니다.

또한 이번 버전에는 **분자 모형 이미지 표시 기능**을 추가했습니다. 실행 후 반응물·생성물의 **분자 모형, 화학식, 계수**를 같은 표에서 볼 수 있어, 숫자 계산과 분자의 모습을 함께 살펴볼 수 있습니다.

화학 반응 정보는 `reactions.txt`에 별도로 저장하여 코드를 수정하지 않고도 새로운 반응을 등록할 수 있도록 구성했습니다.

## 2. 주요 기능

| 기능 | 설명 |
| --- | --- |
| **화학 반응 선택** | 사이드바에서 `reactions.txt`에 등록된 반응을 선택합니다. |
| **반응 정보 표시** | 선택한 반응의 반응식, 종류, 설명을 보여줍니다. |
| **반응 데이터 예외 처리** | 파일이 없거나 유효한 반응이 없으면 기본 반응 2개를 사용합니다. 형식이 잘못된 줄은 경고하고 제외합니다. |
| **반응식 자동 해석** | `->`, `+`를 기준으로 반응물과 생성물을 나누고 각 화학식과 계수를 추출합니다. 생략한 계수는 1로 처리합니다. |
| **초기 분자 수 입력** | 선택한 반응의 반응물 종류만큼 숫자 입력칸이 자동 생성되며, 처음 값과 최솟값은 0입니다. |
| **반응 가능 여부 판단** | 각 반응물의 개수가 해당 반응 계수 이상인지 검사합니다. |
| **단계별 반응 계산** | 한 번 반응할 때 반응물은 계수만큼 감소하고 생성물은 계수만큼 증가합니다. 더 이상 반응할 수 없을 때 종료합니다. |
| **분자 모형 이미지 표** | 실행 후 `images` 폴더의 파일을 찾아 **분자 모형·화학식·계수**를 표로 표시합니다. 이미지가 없으면 해당 화학식을 안내합니다. |
| **단계별 분자 수 표** | 0단계(초기 상태)부터 마지막 단계까지 각 물질의 분자 수를 기록합니다. |
| **단계별 변화 그래프** | 가로축은 반응 단계, 세로축은 분자 수로 하여 각 물질의 변화를 선 그래프로 표시합니다. |
| **최종 결과 설명** | 완전히 소모된 반응물, 다음 단계에 부족한 반응물, 남은 반응물과 생성물의 개수를 설명합니다. |
| **입력 변경 시 결과 초기화** | 반응 선택이나 초기 분자 수를 변경하면 이전 실행 기록을 초기화합니다. |

**실행 방식:** `실행` 버튼을 한 번 누르면 가능한 모든 반응 단계를 자동으로 계산합니다. 단계별 표와 그래프는 **계산 결과를 보여주는 기능**이며, 한 단계씩 수동으로 진행하는 버튼은 현재 구현되어 있지 않습니다. 분자 모형 이미지는 **각 물질의 고정된 이미지**이고, 반응 단계에 따라 이미지 개수가 움직이는 애니메이션은 아닙니다.

## 3. 등록된 반응과 기본 반응

`reactions.txt`에 다음과 같은 반응을 등록하여 사용할 수 있습니다.

| 반응 이름 | 반응식 | 반응 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 반응 |
| 메테인 연소 | `CH4 + 2O2 -> CO2 + 2H2O` | 연소 반응 |

실제 선택 메뉴에 표시되는 반응은 **현재 저장된 `reactions.txt` 내용**에 따라 달라집니다.

파일이 없거나 사용할 수 있는 반응이 하나도 없다면, `main.py`에 준비된 **기본 반응 2개**가 대신 표시됩니다.

| 기본 반응 이름 | 반응식 | 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 |
| 암모니아 합성 | `N2 + 3H2 -> 2NH3` | 합성 |

기본 반응은 평소 메뉴에 자동으로 추가되는 것이 아니라 **파일을 사용할 수 없을 때만 대신 제공**됩니다.

## 4. 프로그램 사용 방법

1. 왼쪽 **사이드바의 `반응 선택`** 메뉴에서 화학 반응을 고릅니다.
2. 메인 화면에서 선택한 반응의 **반응식·종류·설명**을 확인합니다.
3. 반응물별 **초기 분자 수**를 입력합니다.
4. 사이드바의 **`실행`** 버튼을 누릅니다.
5. 실행 후 표시되는 **반응물·생성물 표**에서 분자 모형 이미지, 화학식, 반응 계수를 확인합니다.
6. **단계별 분자 수 표와 변화 그래프**에서 반응물 감소와 생성물 증가를 확인합니다.
7. 마지막으로 **완전히 소모된 반응물, 다음 반응에 부족한 반응물, 남은 반응물, 생성된 물질**의 수를 확인합니다.

반응을 변경하거나 입력한 분자 수를 바꾸면 이전 계산 기록이 지워집니다. 입력을 바꾼 뒤 새 결과를 확인하려면 다시 **실행**해야 합니다.

## 5. 단계별 계산 예시

**물 생성 반응:** `2H2 + O2 -> 2H2O`

초기에 수소 분자(H2) **5개**, 산소 분자(O2) **2개**를 입력하면 한 번의 반응마다 H2 2개와 O2 1개가 소모되고 H2O 2개가 생성됩니다.

| 단계 | H2 | O2 | H2O |
| --- | ---: | ---: | ---: |
| 0 (초기) | 5 | 2 | 0 |
| 1 | 3 | 1 | 2 |
| 2 | 1 | 0 | 4 |

2단계 후에는 O2가 모두 소모되어 반응이 멈춥니다. **H2는 1개 남고 H2O는 총 4개 생성**됩니다.

프로그램은 이 기록을 **표**로 보여주고, `st.line_chart()`를 사용하여 **H2·O2 감소와 H2O 증가**를 선 그래프로 나타냅니다.

위 이미지 파일은 현재 준비한 예시입니다. 다른 반응에 필요한 분자 모형은 같은 방식으로 추가할 수 있습니다. `main.py`와 `images` 폴더는 **같은 저장소의 최상위 위치**에 있어야 합니다.

| `show_screen()` | 반응 선택, 입력, 실행, 결과 저장 및 화면 출력을 연결합니다. |

## 7. 분자 모형 이미지 추가 및 관리

분자 모형 이미지는 GitHub의 `images` 폴더에 저장합니다. 프로그램은 반응식에서 읽은 **화학식과 동일한 이름**의 파일을 찾습니다.

| 물질 | 파일 이름 예시 |
| --- | --- |
| 수소 | `H2.png` |
| 산소 | `O2.png` |
| 물 | `H2O.png` |
| 메테인 | `CH4.png` |
| 이산화탄소 | `CO2.png` |
| 질소(추가할 경우) | `N2.png` |
| 암모니아(추가할 경우) | `NH3.png` |

- 지원하는 확장자는 **`.png`, `.jpg`, `.jpeg`, `.webp`**입니다.
- 파일 이름은 대소문자까지 정확히 일치해야 합니다. 예를 들어 `H2.png`는 인식되지만 `H2.png.png`는 인식되지 않습니다.
- **계수는 파일 이름에 포함하지 않습니다.** 반응식이 `2H2`여도 파일명은 `H2.png`입니다.
- 이미지의 가로세로 비율을 확인하여 표의 이미지 열 너비를 조절하고, 행 높이는 100으로 설정합니다.
- 이미지 파일이 없거나 읽을 수 없으면 해당 이미지 칸을 비우고, 표 아래에 **`이미지 없음: ...`** 문구로 안내합니다.

현재 이미지는 물질별 **분자 모형을 보여주는 정적 자료**입니다. 반응 단계마다 분자 그림의 개수가 바뀌거나 분자가 움직이는 시각화 기능은 포함되어 있지 않습니다.

## 8. 새로운 화학 반응 추가하기

`reactions.txt`에 다음 형식으로 반응 정보를 **한 줄씩** 입력합니다.

```text
이름,반응식,종류,설명
```

예시:

```text
암모니아 생성,N2 + 3H2 -> 2NH3,합성 반응,질소와 수소가 반응하여 암모니아가 생성된다
```

새 반응에 등장하는 물질의 **분자 모형 이미지까지 표시하려면**, `images` 폴더에도 해당 화학식 이름의 이미지 파일을 추가해야 합니다. 이미지가 없어도 화학식과 반응 계수, 단계별 계산은 계속 표시할 수 있습니다.

**작성 시 주의 사항**

- 정보는 반드시 **이름, 반응식, 종류, 설명**의 4개 항목이어야 합니다.
- 현재 코드는 `split(",")`을 사용하므로 설명에도 쉼표를 쓰면 항목 수 오류로 해당 줄이 제외될 수 있습니다.
- 반응물과 생성물은 `->`로, 여러 물질은 `+`로 구분합니다.
- 계수는 화학식 앞에 쓰며, 계수 1은 생략할 수 있습니다.
- **균형이 맞는 반응식과 양의 정수 계수**를 입력해야 합니다. 프로그램은 계수를 자동으로 맞추거나 원자 수 보존을 검증하지 않습니다.

## 9. 예외 처리 및 제한 사항

| 상황 | 처리 방식 |
| --- | --- |
| `reactions.txt`가 없음 | 경고 후 기본 반응 2개를 사용합니다. |
| 파일이 비어 있거나 유효한 반응이 없음 | 경고 후 기본 반응 2개를 사용합니다. |
| 반응 정보의 항목이 4개가 아님 | 줄 번호를 안내하고 해당 줄을 제외합니다. |
| 반응식에 `->`가 없음 | 줄 번호를 안내하고 해당 줄을 제외합니다. |
| 일부 유효한 반응만 존재 | 유효한 반응만 선택 메뉴에 표시합니다. |
| 분자 이미지가 없거나 읽을 수 없음 | 이미지 칸을 비우고 누락된 화학식을 안내합니다. |
| 초기 반응물 개수가 부족함 | 0단계만 기록하고 반응이 진행되지 않았음을 안내합니다. |

**계산 모델의 한계:** 반응식의 정수 계수대로 반응이 완전히 진행되는 **단순화된 분자 수 모델**입니다. 실제 반응 속도, 온도, 압력, 화학 평형, 반응 수율 및 원자 수 보존 여부는 계산하거나 검증하지 않습니다. 반응식 입력의 모든 오류를 자동으로 확인하는 것도 아닙니다.

## 10. 사용 기술 및 배포 방법

- **Python:** 조건문, 반복문, 함수, 리스트, 딕셔너리 등을 활용한 데이터 처리 및 계산
- **Streamlit:** 반응 선택, 수량 입력, 실행 버튼, 표, 선 그래프 및 이미지 표 출력
- **os:** 이미지 파일 경로 탐색 및 존재 여부 확인
- **base64:** 이미지 파일을 표에 표시할 문자열 형태로 변환
- **Pillow (`PIL.Image`):** 원본 이미지의 가로·세로 크기 확인
- **GitHub:** 코드 및 이미지·반응 자료 저장과 변경 기록
- **Streamlit Community Cloud:** 웹 앱 배포

`main.py`에서 `from PIL import Image`를 사용하므로, **`requirements.txt`에 `Pillow`를 명시하는 것을 권장합니다.** 권장 내용은 다음과 같습니다.

```text
streamlit
Pillow
```

> `requirements.txt`는 이 README 작성으로 자동 수정되지 않습니다. 배포 환경에 `Pillow`가 없으면 이미지 관련 기능을 실행하지 못할 수 있으므로 별도로 확인해야 합니다.

### 배포 절차

1. GitHub 저장소에 `main.py`, `reactions.txt`, `requirements.txt`, `README.md`, `images` 폴더를 저장합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속합니다.
3. GitHub 저장소와 브랜치를 선택하고 실행 파일을 `main.py`로 지정합니다.
4. 배포된 앱에서 반응을 고르고 실행하여 분자 이미지, 표, 그래프가 정상 표시되는지 확인합니다.

## 12. 프로젝트 목표

화학 반응식을 단순히 암기하는 데 그치지 않고, **반응 계수가 실제 분자 수 변화와 어떤 관계를 가지는지** 사용자가 직접 조건을 설정하고 결과를 확인하며 이해하는 것이 목표입니다. 계산 결과를 표와 그래프로 정리하고 분자 모형 이미지와 연결함으로써 화학 반응의 양적 관계를 더 직관적으로 학습할 수 있도록 하였습니다.

또한 반응 데이터·분자 이미지·프로그램 코드를 분리하고 기능별로 함수를 구성하여, 새로운 반응을 추가하거나 기능을 확장하기 쉬운 구조를 만들고자 했습니다.
