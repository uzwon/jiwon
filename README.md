# 🧪 화학 반응 단계별 시뮬레이터

## 1. 프로젝트 소개

**화학 반응 단계별 시뮬레이터**는 화학 반응식의 계수에 따라 반응물과 생성물의 분자 수가 단계별로 어떻게 변하는지 계산하고, 그 결과를 **표·그래프·분자 모형 이미지**로 확인할 수 있는 Python 기반 **Streamlit 웹 프로그램**입니다.

사용자는 화학 반응을 선택하고 반응물의 초기 분자 수를 입력한 뒤 메인 화면의 **`실행`** 버튼을 누를 수 있습니다. 프로그램은 반응이 가능한 동안 반응을 한 단계씩 반복 계산하고, 최종적으로 남은 반응물과 생성물의 개수를 분석합니다.

화학 반응 정보는 `reactions.txt`로, 분자 모형은 `images` 폴더로, 화면 디자인은 `style.css`로 분리해 관리합니다. 또한 사이드바에서 직접 반응을 추가하거나 삭제할 수 있도록 구성했습니다.

## 2. 주요 기능

| 기능 | 설명 |
| --- | --- |
| **화학 반응 선택** | 사이드바에서 등록된 반응을 선택합니다. |
| **반응 직접 추가** | 사이드바의 `반응 추가` 양식에 이름·반응식·종류·설명을 입력해 현재 세션의 반응 목록에 추가합니다. |
| **선택한 반응 삭제** | 사이드바에서 현재 선택한 반응을 목록에서 삭제합니다. |
| **반응식 기본 형식 검사** | 추가할 때 반응 이름 중복, 화살표 개수, 계수·화학식의 일부 형식 오류 등을 검사합니다. |
| **반응 데이터 예외 처리** | `reactions.txt`가 없거나 유효한 반응이 없으면 기본 반응 2개를 사용합니다. 형식이 잘못된 줄은 경고 후 제외합니다. |
| **반응식 자동 해석** | 반응물을 생성물과 나누고 각 화학식·반응 계수를 추출합니다. 계수가 생략되면 `1`로 처리합니다. |
| **초기 분자 수 입력** | 선택한 반응의 반응물 종류만큼 입력칸이 자동으로 만들어집니다. 초기값과 최솟값은 `0`입니다. |
| **단계별 반응 계산** | 모든 반응물이 충분할 때 반응물은 계수만큼 감소하고 생성물은 계수만큼 증가합니다. 더 이상 진행할 수 없을 때 종료합니다. |
| **분자 모형 이미지 표** | 실행 후 `images` 폴더의 이미지와 화학식·계수를 HTML 표로 표시하고, 이미지가 없는 물질은 안내합니다. |
| **단계별 분자 수 표** | 초기 상태(0단계)부터 마지막 반응 단계까지의 분자 수를 표시합니다. |
| **맞춤형 선 그래프** | Vega-Lite로 단계별 분자 수 변화를 표시하며, `style.css`의 색상 정보를 그래프에 반영합니다. |
| **최종 결과 설명** | 완전히 소모된 반응물, 다음 단계에 부족한 반응물, 남은 반응물 및 생성물을 설명합니다. |
| **입력 변경 시 기록 초기화** | 선택한 반응이나 입력한 분자 수가 달라지면 이전 계산 기록을 초기화합니다. |
| **다크 모드 화면 디자인** | `style.css`와 Pretendard 폰트 설정을 이용해 시뮬레이터 화면을 꾸밉니다. |

**실행 방식:** `실행` 버튼을 한 번 누르면 가능한 반응 단계가 전부 계산됩니다. 단계별 기록은 표와 그래프로 볼 수 있지만, **한 단계씩 별도로 실행하는 버튼은 없습니다.** 분자 모형 이미지도 단계마다 움직이거나 개수가 변하는 애니메이션이 아니라 각 물질의 **고정된 이미지**입니다.

## 3. 등록된 반응과 기본 반응

프로그램은 첫 실행 시 `reactions.txt`를 읽어 반응 목록을 구성합니다. 예를 들어 다음과 같이 등록할 수 있습니다.

| 반응 이름 | 반응식 | 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 반응 |
| 메테인 연소 | `CH4 + 2O2 -> CO2 + 2H2O` | 연소 반응 |

**실제 목록은 저장소의 `reactions.txt` 내용과 현재 세션에서 추가·삭제한 내용에 따라 달라집니다.**

`reactions.txt` 파일이 없거나 사용할 수 있는 반응이 하나도 없는 경우에는 코드에 포함된 다음 기본 반응 2개를 대신 사용합니다.

| 기본 반응 이름 | 반응식 | 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 |
| 암모니아 합성 | `N2 + 3H2 -> 2NH3` | 합성 |

기본 반응은 정상적인 `reactions.txt`가 있는 경우 메뉴에 별도로 자동 추가되지 않습니다.

## 4. 프로그램 사용 방법

1. 왼쪽 **사이드바의 `반응 선택`** 메뉴에서 실험할 반응을 고릅니다. 필요하면 사이드바의 `반응 추가`에서 새 반응을 등록할 수 있습니다.
2. 메인 화면에서 선택한 반응의 **반응식·종류·설명**을 확인합니다.
3. 반응물별 **초기 분자 수**를 입력합니다.
4. 입력칸 아래 메인 화면에 있는 **`실행`** 버튼을 누릅니다.
5. **반응물·생성물 표**에서 분자 모형 이미지, 화학식, 반응 계수를 확인합니다.
6. **단계별 분자 수 표와 변화 그래프**에서 각 물질의 수량 변화를 확인합니다.
7. **최종 결과 설명**에서 소모·부족·잔여 반응물과 생성물의 개수를 확인합니다.

반응이나 입력값을 바꾸면 이전 실행 결과는 지워지며, 새 결과를 보려면 다시 `실행` 버튼을 눌러야 합니다. 사이드바의 `선택한 반응 삭제`를 누르면 현재 목록에서 해당 반응이 삭제됩니다.

**주의:** 사이드바에서 추가·삭제한 내용은 `st.session_state`에 보관되며, **`reactions.txt`에 자동 저장되지 않습니다.** 따라서 새 세션이나 앱 재시작 시에는 파일에 저장된 반응 목록으로 돌아갈 수 있습니다. 영구적으로 반응을 등록하려면 `reactions.txt`를 별도로 수정해야 합니다.

## 5. 단계별 계산 예시

**물 생성 반응:** `2H2 + O2 -> 2H2O`

초기에 **H2 5개**, **O2 2개**를 입력하면 반응이 한 번 일어날 때마다 H2 2개와 O2 1개가 소모되고 H2O 2개가 생성됩니다.

| 단계 | H2 | O2 | H2O |
| --- | ---: | ---: | ---: |
| 0 (초기) | 5 | 2 | 0 |
| 1 | 3 | 1 | 2 |
| 2 | 1 | 0 | 4 |

2단계 후에는 O2가 모두 소모되어 반응이 종료됩니다. **H2 1개가 남고 H2O 4개가 생성**됩니다. 프로그램은 이를 표와 물질별 선 그래프로 나타냅니다.

## 7. 분자 모형 이미지 추가 및 관리

분자 모형 이미지는 `main.py`와 같은 위치에 있는 `images` 폴더에 저장합니다. 프로그램은 **화학식과 이름이 같은 이미지 파일**을 찾습니다.

| 물질 | 이미지 파일명 예시 |
| --- | --- |
| 수소 | `H2.png` |
| 산소 | `O2.png` |
| 물 | `H2O.png` |
| 메테인 | `CH4.png` |
| 이산화탄소 | `CO2.png` |
| 질소 | `N2.png` |
| 암모니아 | `NH3.png` |

지원 확장자는 `.png`, `.jpg`, `.jpeg`, `.webp`이고, **대소문자가 일치해야** 합니다. 예를 들어 `H2.png.png`는 `H2.png`와 다른 파일이므로 인식되지 않습니다. 반응 계수는 파일명에 포함하지 않습니다.

분자 이미지가 없다면 표의 이미지 칸을 비워 두고 `이미지 없음: ...` 안내를 표시합니다. 현재 코드는 이미지 크기를 Pillow로 확인하거나 이미지 자체를 확대·축소해 저장하지 않으며, **HTML의 `<img>` 태그로 표에 표시**합니다.

## 8. 새로운 반응 추가·삭제 및 데이터 관리

### ① 앱의 사이드바에서 직접 추가하기

`반응 추가` 영역에 **반응 이름, 반응식, 종류, 설명**을 입력한 다음 `추가` 버튼을 누릅니다. 반응식 입력 길이는 최대 **200자**입니다. 기존 이름과 중복되지 않고 기본 형식 검사를 통과하면 선택 메뉴에 추가됩니다.

### ② `reactions.txt`에 저장하여 등록하기

지속적으로 사용할 반응을 등록하려면 `reactions.txt`에 아래 형식으로 한 줄씩 작성합니다.

```text
이름,반응식,종류,설명
```

예시:

```text
암모니아 생성,N2 + 3H2 -> 2NH3,합성 반응,질소와 수소가 반응하여 암모니아가 생성된다
```

파일에 추가한 반응은 앱이 해당 파일을 다시 읽는 새 세션이나 재시작 시 초기 목록에 반영됩니다. `reactions.txt`에서 잘못된 행은 경고 후 제외됩니다.

### ③ 반응 삭제하기

사이드바에서 반응을 선택한 다음 `선택한 반응 삭제`를 누르면 **현재 세션의 목록**에서 제거됩니다. 이 작업은 `reactions.txt`의 원본 데이터를 삭제하지 않습니다.

**반응식 입력 규칙**

- 반응물과 생성물은 `->` 하나로 구분하고, 여러 물질은 `+`로 연결합니다.
- 반응 계수는 화학식 앞에 적고, 계수 `1`은 생략할 수 있습니다.
- 사이드바 직접 추가에서는 반응식에 ASCII 문자만 허용하며, 각 물질은 대문자로 시작해야 하고 계수는 양의 정수여야 합니다.
- 같은 쪽에 같은 화학식을 중복 작성하면 추가가 거부됩니다. 같은 물질은 계수로 묶어 작성합니다.
- `reactions.txt`는 쉼표로 나뉜 항목이 정확히 4개여야 하므로 설명에 쉼표를 넣지 않는 것이 좋습니다.
- **화학식의 실제 타당성, 원소별 원자 수 보존, 반응 계수의 균형은 자동 검증하지 않습니다.**

## 9. 오류 처리 및 현재 제한 사항

| 상황 | 프로그램 동작 또는 제한 |
| --- | --- |
| `reactions.txt`가 없음 | 경고를 보여주고 기본 반응 2개를 사용합니다. |
| 파일이 비어 있거나 유효한 반응이 없음 | 경고 후 기본 반응 2개를 사용합니다. |
| 파일의 행에 항목이 4개가 아니거나 `->`가 없음 | 해당 줄을 건너뛰고 경고를 보여줍니다. |
| 사이드바에서 반응 이름이 비어 있거나 중복됨 | 추가를 거부하고 경고합니다. |
| 사이드바 입력 반응식이 기본 형식 검사를 통과하지 못함 | 추가를 거부하고 경고합니다. |
| 이미지 파일이 없음 | 이미지 칸을 비우고 누락된 물질을 안내합니다. |
| 초기 반응물이 부족함 | 0단계만 기록하고 반응이 일어나지 않았음을 안내합니다. |
| `style.css` 파일이 없음 | 현재 코드에서는 파일을 직접 읽으므로 앱 실행이 실패할 수 있습니다. |
| `style.css`에 필요한 색상 변수가 없음 | 그래프 표시 시 해당 색상을 조회하는 과정에서 오류가 발생할 수 있습니다. |

현재 `valid_equation()`은 **간단한 문자열 형식 검사**이므로, 모든 잘못된 화학식을 판별하는 기능은 아닙니다. 또한 `reactions.txt`를 읽는 단계의 검사는 파일 행의 항목 수와 `->` 포함 여부 중심으로, 사이드바 직접 입력 검사와 수준이 다릅니다.

이 프로그램은 반응식의 정수 계수대로 반응이 진행된다고 가정하는 **단순화된 분자 수 모델**입니다. 실제 온도·압력·반응 속도·화학 평형·수율 등은 계산하지 않습니다.

## 10. 사용 기술 및 배포 방법

- **Python:** 조건문, 반복문, 함수, 리스트 및 딕셔너리를 이용한 데이터 처리
- **Streamlit:** 사이드바, 반응 추가 양식, 입력창, 버튼, 표·그래프 등 웹 인터페이스 구현
- **Vega-Lite (`st.vega_lite_chart`)**: 물질별 분자 수의 단계별 변화를 맞춤형 선 그래프로 표시
- **HTML·CSS:** 분자 모형 표 출력과 화면 디자인
- **Pretendard:** `style.css`에서 지정하는 화면용 글꼴
- **`os`, `base64`, `html`, `re`, `pathlib`:** 이미지 경로·인코딩, 텍스트 안전 처리 및 디자인 파일 관리에 사용하는 Python 표준 라이브러리
- **GitHub:** 파일과 커밋 기록 관리
- **Streamlit Community Cloud:** 웹 앱 배포

현재 `main.py`에는 Pillow의 `PIL` 가져오기 코드가 없으므로, **Pillow는 이 파일의 필수 직접 의존성이 아닙니다.** 기본 `requirements.txt`는 다음과 같이 작성할 수 있습니다.

```text
streamlit
```

**디자인 파일 확인:** `style.css`에는 화면 스타일뿐 아니라 그래프에 전달할 다음 색상 변수도 필요합니다: `--surface`, `--text`, `--highlight`, `--border`, `--accent`, `--chart-muted`, `--hover`. 현재 코드는 이 변수들을 정규식으로 읽어 그래프 설정에 사용하므로, 각 값을 `#RRGGBB` 형식으로 지정해야 합니다.

### 배포 방법

1. GitHub 저장소에 `main.py`, `style.css`, `reactions.txt`, `requirements.txt`, `README.md`, `images` 폴더를 저장합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속해 저장소와 브랜치를 선택합니다.
3. 메인 실행 파일을 `main.py`로 설정하여 배포합니다.
4. 반응 추가·선택·삭제, 실행, 분자 모형 표, 단계별 그래프가 의도대로 작동하는지 직접 확인합니다.

## 12. 프로젝트 목표

화학 반응식을 단순히 암기하는 데 그치지 않고, **반응 계수가 실제 분자 수 변화와 어떤 관계를 가지는지** 사용자가 직접 조건을 설정하고 결과를 확인하며 이해하는 것이 목표입니다. 계산 결과를 표와 그래프로 정리하고 분자 모형 이미지와 연결함으로써 화학 반응의 양적 관계를 더 직관적으로 학습할 수 있도록 하였습니다.

또한 반응 데이터·분자 이미지·프로그램 코드를 분리하고 기능별로 함수를 구성하여, 새로운 반응을 추가하거나 기능을 확장하기 쉬운 구조를 만들고자 했습니다.
