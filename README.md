# 🧪 화학 반응 단계별 시뮬레이터

## 1. 프로젝트 소개

**화학 반응 단계별 시뮬레이터**는 화학 반응식의 계수에 따라 반응물과 생성물의 분자 수가 어떻게 변하는지 계산하고 시각화하는 **Streamlit 웹 프로그램**입니다.

사용자가 반응을 선택하고 반응물의 초기 분자 수를 입력한 뒤 **실행** 버튼을 누르면, 반응물이 충분한 동안 반응을 한 단계씩 계산합니다. 계산 결과는 **단계별 분자 수 표**, **변화 그래프**, **최종 결과 설명**으로 확인할 수 있습니다.

프로그램은 Python의 조건문, 반복문, 함수, 리스트 등을 활용하여 구현했으며, 화학 반응 정보는 코드와 분리된 `reactions.txt` 파일에서 관리합니다.

## 2. 주요 기능

| 기능 | 설명 |
| --- | --- |
| **화학 반응 선택** | 사이드바에서 `reactions.txt`에 등록된 반응을 선택합니다. |
| **반응 정보 표시** | 선택한 반응의 반응식, 종류, 설명을 표시합니다. |
| **반응 데이터 예외 처리** | 파일이 없거나 사용 가능한 반응이 없으면 기본 반응 2개를 제공합니다. 항목 수 또는 화살표가 잘못된 줄은 안내하고 제외합니다. |
| **반응식 자동 해석** | `->`, `+`로 반응물과 생성물을 구분하고 각 물질의 화학식과 계수를 추출합니다. 생략한 계수는 `1`로 처리합니다. |
| **초기 분자 수 입력** | 선택한 반응의 반응물 종류만큼 숫자 입력칸이 자동 생성됩니다. 초기값과 최솟값은 `0`입니다. |
| **반응 가능 여부 확인** | 모든 반응물의 분자 수가 각각의 반응 계수 이상인지 검사합니다. |
| **단계별 반응 계산** | 반응이 한 번 진행될 때마다 반응물은 계수만큼 감소하고 생성물은 계수만큼 증가합니다. 더 이상 반응할 수 없을 때 자동 종료합니다. |
| **화학식·계수 표** | 선택된 반응의 반응물 및 생성물 정보를 각각 표로 표시합니다. |
| **단계별 분자 수 표** | 초기 상태(0단계)부터 종료 시점까지 각 물질의 분자 수를 기록합니다. |
| **단계별 변화 그래프** | `st.line_chart()`를 사용해 반응 단계에 따른 각 물질의 분자 수를 꺾은선그래프로 나타냅니다. |
| **최종 결과 분석** | 완전히 소모된 반응물, 다음 단계에 부족한 반응물, 남은 반응물과 생성된 물질의 개수를 문장으로 설명합니다. |
| **입력 변경 시 기록 초기화** | 선택한 반응이나 초기 분자 수가 바뀌면 기존 계산 기록을 초기화합니다. |

**참고:** 현재 코드는 실행 버튼을 한 번 누르면 가능한 모든 반응 단계를 연속 계산합니다. 단계별 결과를 표와 그래프로 확인할 수 있지만, 단계마다 버튼을 다시 누르는 방식은 아닙니다.

## 3. 등록된 반응과 기본 반응

기존 `reactions.txt`에 작성한 반응 예시는 다음과 같습니다.

| 반응 이름 | 반응식 | 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 반응 |
| 메테인 연소 | `CH4 + 2O2 -> CO2 + 2H2O` | 연소 반응 |

**파일을 읽지 못하거나 사용 가능한 반응이 없는 경우**에는 `main.py`에 설정된 다음 기본 반응 2개가 대신 표시됩니다.

| 기본 반응 이름 | 반응식 | 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 |
| 암모니아 합성 | `N2 + 3H2 -> 2NH3` | 합성 |

실제 메뉴는 `reactions.txt` 파일의 내용에 따라 달라집니다. 파일에 유효한 반응 정보가 있으면 그 반응을 사용하고, 기본 반응이 항상 추가되는 것은 아닙니다.

## 4. 프로그램 사용 방법

1. 왼쪽 **사이드바의 '반응 선택'** 메뉴에서 화학 반응을 고릅니다.
2. 메인 화면에서 선택한 반응의 **반응식·종류·설명**을 확인합니다.
3. 각 반응물의 **초기 분자 수**를 입력합니다.
4. **반응물·생성물의 화학식과 계수 표**를 확인합니다.
5. 사이드바의 **'실행'** 버튼을 누릅니다.
6. **단계별 분자 수 표**와 **단계별 분자 수 변화 그래프**를 확인합니다.
7. 마지막으로 **소모된 반응물, 부족한 반응물, 남은 반응물, 생성물**에 대한 분석 결과를 확인합니다.

입력값 또는 선택한 반응을 변경하면 이전 결과는 자동으로 초기화됩니다.

## 5. 단계별 계산 예시

**물 생성 반응:** `2H2 + O2 -> 2H2O`

초기 분자 수가 H2 **5개**, O2 **2개**인 경우, 한 번의 반응마다 H2는 2개, O2는 1개 감소하고 H2O는 2개 생성됩니다.

| 단계 | H2 | O2 | H2O |
| --- | ---: | ---: | ---: |
| 0 (초기) | 5 | 2 | 0 |
| 1 | 3 | 1 | 2 |
| 2 | 1 | 0 | 4 |

2단계 후에는 O2가 0개가 되어 더 이상 반응할 수 없습니다. **H2는 1개 남고 H2O는 총 4개 생성**됩니다.

프로그램은 위와 같은 단계별 기록을 **표**로 표시하며, 그래프에는 H2와 O2의 감소 및 H2O의 증가가 각각의 선으로 나타납니다. 그래프의 가로축은 **단계**, 세로축은 **분자 수**입니다.

```text
chemistry-reaction-simulator/
├── main.py           # 반응 정보 읽기, 계산, 표·그래프 및 화면 구성
├── reactions.txt     # 반응 이름, 반응식, 종류, 설명 데이터
├── requirements.txt  # Streamlit 라이브러리 설치 설정
└── README.md         # 프로젝트 소개 및 사용 방법
```

### `main.py`의 함수별 역할

| 함수 | 역할 |
| --- | --- |
| `read_reactions()` | 텍스트 파일에서 반응 정보를 읽고, 파일 누락·잘못된 줄·빈 파일 등에 대응합니다. |
| `parse_reaction()` | 반응식을 반응물·생성물로 나누고 화학식 및 계수를 추출합니다. |
| `react_once()` | 반응 가능 여부를 검사하고, 가능한 경우 분자 수를 한 단계 변경합니다. |
| `show_table()` | 반응물 또는 생성물의 화학식과 계수를 표로 표시합니다. |
| `show_history_table()` | 각 반응 단계의 분자 수를 표로 표시합니다. |
| `show_history_chart()` | 같은 단계별 기록을 사용해 분자 수 변화 그래프를 그립니다. |
| `show_result()` | 마지막 상태를 분석해 소모·부족·잔여 반응물과 생성물 개수를 설명합니다. |
| `show_screen()` | 반응 선택, 입력, 실행, 기록 저장, 표·그래프·결과 출력 기능을 연결합니다. |

## 7. 새로운 화학 반응 추가하기

`reactions.txt` 파일에 아래 형식으로 반응을 **한 줄씩** 입력합니다.

```text
이름,반응식,종류,설명
```

예시:

```text
암모니아 생성,N2 + 3H2 -> 2NH3,합성 반응,질소와 수소가 반응하여 암모니아가 생성된다
```

GitHub에서 파일을 수정하고 배포 앱이 업데이트되면 선택 메뉴에서 새로운 반응을 고를 수 있습니다.

**작성 시 주의 사항**

- 쉼표로 구분한 항목이 **정확히 네 개**여야 합니다. 현재 코드는 `split(",")`을 사용하므로 설명에도 쉼표를 넣으면 해당 줄이 제외될 수 있습니다.
- 반응물과 생성물 사이에는 `->`를, 여러 물질 사이에는 `+`를 사용합니다.
- 계수는 화학식 앞에 적고, `1`은 생략할 수 있습니다.
- **균형이 맞는 반응식과 양의 정수 계수**를 입력해야 합니다. 현재 프로그램은 원자 수 보존 여부나 계수의 타당성을 자동 검증하지 않습니다.
- 현재의 형식 검사는 **항목 수와 `->` 포함 여부**가 중심이며, 모든 잘못된 반응식을 자동으로 감지하지는 못합니다.

## 8. 예외 처리 및 데이터 관리

`read_reactions()` 함수에는 다음 상황에 대한 처리가 구현되어 있습니다.

| 상황 | 프로그램 동작 |
| --- | --- |
| `reactions.txt` 파일이 없음 | 경고를 출력하고 **물 생성·암모니아 합성** 기본 반응 2개를 사용합니다. |
| 빈 파일 또는 공백만 있는 파일 | 경고를 출력하고 기본 반응 2개를 사용합니다. |
| 쉼표로 나뉜 항목이 4개가 아닌 줄 | 해당 줄 번호와 이유를 경고하고 건너뜁니다. |
| 반응식에 `->`가 없는 줄 | 해당 줄 번호와 이유를 경고하고 건너뜁니다. |
| 유효한 반응이 하나도 없음 | 경고를 출력하고 기본 반응 2개를 사용합니다. |
| 유효한 반응과 잘못된 줄이 함께 있음 | 잘못된 줄만 제외하고 유효한 반응을 메뉴에 표시합니다. |

이러한 처리는 `reactions.txt`를 관리할 때 생길 수 있는 일부 입력 오류로 인해 반응 선택 메뉴가 비는 것을 방지하기 위한 기능입니다.

## 9. 사용 기술 및 배포

- **Python:** 변수, 조건문, 반복문, 함수, 리스트, 딕셔너리를 활용한 데이터 처리 및 단계별 계산
- **Streamlit:** 반응 선택 메뉴, 숫자 입력창, 실행 버튼, 표 및 꺾은선그래프
- **GitHub:** 프로그램 소스 코드와 화학 반응 정보 관리
- **Streamlit Community Cloud:** 웹 앱 배포

`requirements.txt`의 기본 내용:

```text
streamlit
```

### 배포 방법

1. GitHub 저장소에 `main.py`, `reactions.txt`, `requirements.txt`, `README.md`를 저장합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속합니다.
3. 배포할 저장소와 브랜치를 선택합니다.
4. 실행 파일을 `main.py`로 지정하여 배포합니다.

## 10. 구현 범위 및 제한 사항

- **화학 반응 모델:** 반응식의 정수 계수에 맞춰 분자 수가 소모·생성된다고 가정합니다. 실제 반응 속도, 온도, 압력, 화학 평형 및 반응 수율은 계산하지 않습니다.
- **반응식 검증:** 입력 데이터에 대한 기본 형식 검사만 수행합니다. 화학식의 원자 구성이나 반응식 균형을 검사하지 않습니다.
- **단계별 진행 방식:** 실행 버튼으로 가능한 모든 단계를 연속 계산하며, 각 단계는 실행 후 표와 그래프에서 확인합니다.
- **그래프 표시:** 실제 실행 결과를 `st.line_chart()`에 전달하도록 구현되어 있습니다. 배포 환경에 따른 화면 표시 상태는 별도 확인이 필요합니다.
- **분자 모형 이미지:** 현재 이 버전의 `main.py`에는 2D 분자 이미지 표시 기능이 포함되어 있지 않습니다.
