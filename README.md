# 🧪 화학 반응 단계별 시뮬레이터

## 1. 프로젝트 소개

**화학 반응 단계별 시뮬레이터**는 화학 반응식을 선택하고 반응물의 분자 개수를 입력하면서, 반응식의 구성과 계수를 살펴볼 수 있도록 만든 웹 프로그램입니다.

파이썬의 **변수, 조건문, 반복문, 함수, 리스트**를 활용하고, **Streamlit**으로 화면을 구성했습니다. 화학 반응 정보를 `reactions.txt` 파일에 따로 저장해 새로운 반응을 쉽게 추가할 수 있도록 설계했습니다.

> **현재 개발 단계:** 반응 선택, 반응식 해석, 반응물 개수 입력, 결과 표시는 구현했습니다. 분자 수를 실제로 변화시키는 **단계별 반응 계산 기능은 아직 구현하지 않았습니다.**

## 2. 현재 구현된 기능

- **화학 반응 선택:** 사이드바에서 `reactions.txt`에 등록된 반응 중 하나를 선택할 수 있습니다.
- **반응식 해석:** `2H2 + O2 -> 2H2O` 같은 반응식을 반응물과 생성물로 나누고, 각각의 화학식과 계수를 추출합니다. 계수가 적혀 있지 않으면 `1`로 처리합니다.
- **반응물 분자 수 입력:** 선택한 반응의 반응물 종류에 맞춰 숫자 입력칸이 자동으로 나타납니다.
- **해석 결과 표:** 반응물·생성물의 화학식과 계수를 표로 표시합니다.
- **반응 데이터 분리:** 새 반응을 추가할 때는 파이썬 코드를 수정하지 않고 `reactions.txt`에 한 줄을 추가할 수 있습니다.

## 3. 등록된 화학 반응

| 반응 이름 | 반응식 | 종류 |
| --- | --- | --- |
| 물 생성 | `2H2 + O2 -> 2H2O` | 합성 반응 |
| 메테인 연소 | `CH4 + 2O2 -> CO2 + 2H2O` | 연소 반응 |

## 4. 사용 방법

1. 앱을 열고 왼쪽 **사이드바**에서 화학 반응을 선택합니다.
2. 화면에 표시된 반응식을 확인합니다.
3. 각 반응물의 분자 개수를 입력합니다.
4. 아래 표에서 반응물과 생성물의 화학식 및 계수를 확인합니다.

**주의:** 현재 입력한 분자 개수로 반응을 진행하거나 남은 분자 수를 계산하지는 않습니다.

## 5. 프로젝트 파일 구조

```text
chemistry-reaction-simulator/
├── main.py           # Streamlit 화면 및 반응식 해석 코드
├── reactions.txt     # 화학 반응 정보
├── requirements.txt  # 필요한 파이썬 라이브러리
└── README.md         # 프로젝트 설명 문서
```

| 파일명 | 역할 |
| --- | --- |
| `main.py` | 파일 읽기, 반응식 해석, 화면 표시 기능을 담당합니다. |
| `reactions.txt` | 반응 이름·반응식·종류·설명을 저장합니다. |
| `requirements.txt` | Streamlit 설치에 필요한 정보를 담습니다. |
| `README.md` | 프로그램의 목적, 기능, 사용 방법을 설명합니다. |

## 6. 새로운 화학 반응 추가 방법

`reactions.txt`를 열어 아래 형식으로 **새로운 한 줄**을 추가합니다.

```text
이름,반응식,종류,설명
```

작성 예시:

```text
암모니아 생성,N2 + 3H2 -> 2NH3,합성 반응,질소와 수소가 반응하여 암모니아가 생성된다
```

파일을 저장한 뒤 앱을 다시 실행하면 해당 반응이 선택 메뉴에 표시됩니다.

- 각 항목은 쉼표(`,`)로 구분합니다.
- 반응물과 생성물은 `->`로 구분하고, 각 물질은 `+`로 구분합니다.
- 화학식 앞의 숫자는 반응 계수입니다. 계수 `1`은 생략할 수 있습니다.
- 반응식은 **화학적으로 균형이 맞게** 직접 작성해야 합니다. 현재 프로그램은 반응식의 균형을 자동 검증하지 않습니다.

## 7. 사용 기술

- **Python:** 함수와 리스트 등을 사용한 데이터 처리
- **Streamlit:** 웹 화면 및 입력칸 구현
- **GitHub:** 코드와 데이터 파일 관리
- **Streamlit Community Cloud:** 웹 앱 배포

## 8. 실행 및 배포

이 프로젝트는 GitHub 웹사이트에서 파일을 작성하고, **Streamlit Community Cloud**로 배포하도록 구성했습니다.

1. GitHub 저장소에 `main.py`, `reactions.txt`, `requirements.txt`, `README.md`를 저장합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에서 GitHub 저장소를 연결합니다.
3. 실행 파일 경로를 `main.py`로 지정하고 배포합니다.

`requirements.txt` 내용:

```text
streamlit
```

## 10. 프로젝트 목표

최종적으로 **화학 반응식의 계수와 실제 분자 개수의 관계**를 단계별로 확인하는 시뮬레이터를 만드는 것이 목표입니다. 반응 데이터를 코드와 분리하여, 프로그램 구조를 크게 바꾸지 않고도 다양한 반응을 추가할 수 있도록 발전시킬 계획입니다.
